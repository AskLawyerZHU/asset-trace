# 执行财产速查 · asset-trace

一个给律师用的执行财产线索检索 Skill：**输入被执行人信息，一键跑完公开渠道可查项，产出《财产线索检索报告》**。

适用于 WorkBuddy / Claude Skills 等支持 `SKILL.md` 规范的 Agent 环境。

## 它解决什么问题

公开渠道能查的东西散在十几个站点，能查什么、查到什么程度、哪些根本查不到，通常靠个人经验。查漏了不会报错，但会直接影响执行方案。

本 Skill 把这些经验固化成流程：**能机器查的自动查，查不到的明说去哪拿，未查的绝不写成"没有"**。

## 核心设计

### 三层渠道

| 层级 | 内容 | 处理 |
|---|---|---|
| **A 机器可查** | 法律数据库 MCP（元典）、企查查类连接器 | 技能内自动执行 |
| **B 半自动** | 执行信息公开网四库、中登网、司法拍卖、公告网、国家企业信用信息公示系统、第三方风险库 | 不硬爬（反爬多变易失效），生成"操作路径卡"交人工，贴回结果后二次分析 |
| **C 公开不可查** | 银行流水、不动产、车辆、证券、保险、社保公积金、婚姻财产 | 自动生成调查令方向清单 |

### 五步流程

1. **输入体检** — 主体分流（自然人 / 法人）；自然人强制同名甄别
2. **连接器探测** — 探测元典/企查查可用性，不可用即降级并标注，禁止含糊写"均已核验"
3. **批量检索** — 自然人 15 线 / 法人 6 层穿透，逐线执行并记录来源与查询日
4. **线索评估** — P0 立即行动 → P3 观察，附对应法律动作与"可执行距离"
5. **报告产出** — 六件套：画像卡 / 线索池 / **查全度核对表** / 人工待办 + 调查令清单 / 行动 SOP / 核验声明

## 与常见"渠道清单"的区别

- **查全度管理**：每条线标 `✅已核验` / `❗冲突` / `⏳未查` / `⛔公开不可查`，`查到 0 件` 与 `没查` 严格区分
- **同名甄别前置**：自然人未锁定身份不出任何财产结论（保留排除理由）
- **单源无记录不作反证**：实战中遇到过文书库显示无执行记录、实际有多件终本的情况
- **渠道卡可维护**：站点改版只改对应卡，主流程不动
- **可降级分享**：不绑定私有凭据，没有 MCP 也能当"检索指引 + 待办生成器"用

## 安装

```bash
# 用户级（对所有项目生效）
cp -r asset-trace ~/.workbuddy/skills/

# 或项目级
cp -r asset-trace <your-project>/.workbuddy/skills/
```

## 使用

```
帮我查一下 <公司全名> 的财产线索，深度模式
查 <姓名>（身份证号 xxx）的财产线索
```

## 边界

- 不替代法院网络查控、律师调查令、现场调查；产出是"公开面的天花板 + 下一步路径"
- 不做绕过验证码/登录的爬虫
- 未核验信息不作确定性表述；涉个人隐私信息仅限执行用途提示

## 免责

本 Skill 提供检索方法论与流程编排，不构成法律意见。具体案件请结合现行有效法律法规及司法解释判断。
