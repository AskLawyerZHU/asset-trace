# 渠道矩阵总表

全矩阵总览。层级：A=机器可查（本技能自动跑）｜B=半自动（公开但需登录/交互，列入人工待办）｜C=公开不可查（进调查令方向清单）。「基线 ID」列 = SKILL.md 法人基线 F1–F12 / 自然人基线 N1–N9 / 扩展项 E1–E17 的映射，核对表按基线 ID 登记，本表 # 号仅是检索动线顺序。

> 反爬与改版风险集中在 B 层。某渠道失效时：改标 ⏳（渠道暂不可用），只更新对应"渠道卡"，不改主流程。

## 使用规则

1. Step 3 按"一→五"顺序逐项跑 A 层；B 层在快速模式下列入人工待办，深度模式下逐项给路径请用户贴回结果。
2. 每项查完立即在报告"查全度核对表"按**基线 ID**登记状态（✅/❗/⏳/⛔）+ 来源 + 查询日；一条基线对应多渠道时，登记一次（来源写主渠道，交叉源写进说明）。
3. ⛔ 仅用于 C 层：标"公开不可查，见调查令清单"。
