# 程序期限与时效表（执行财产线索专用）

> 纪律：本表为速查索引，条文号以现行有效版本为准（可用元典法条接口核原文）；具体案件的期限计算以法院核算为准。

## 一、债权端（申请执行人视角）

| 事项 | 期限 | 依据与要点 |
|---|---|---|
| 申请执行时效 | **2 年**，自生效法律文书确定的履行期最后一日起算 | 民诉法第 246 条；适用时效中止、中断 |
| 终本后恢复执行 | **不受 2 年时效限制**，发现财产随时可申请 | 民诉法解释第 519 条第 2 款——终本不是终点，是待机 |
| 恢复执行（执行和解后不履行） | 2 年，自和解协议约定履行期限最后一日起算 | 申请恢复执行**原生效法律文书** |
| 执行行为异议 | 执行程序终结前提出 | 对裁定不服的救济路径分复议/异议之诉 |
| 案外人异议 | 执行标的执行终结前 | 涉案外财产权属时注意 |
| 追加被执行人 | 执行过程中提出申请 | 法院一般 60 日内裁定（特殊可延长）；追加范围法定，不能随意扩 |
| 债权人撤销权（无偿转让/明显低价） | **1 年**（知道或应知撤销事由起）/ **5 年**（行为发生日起，最长） | 民法典第 541 条；低价转让房产给亲属=典型场景 |
| 债权人代位权 | 主债权诉讼时效内行使 | 民法典第 535–537 条；被执行人怠于行使其到期债权时 |
| 参与分配（被执行人为自然人/其他组织） | 执行程序开始后、**被执行人财产执行终结前**申请 | 民诉法解释第 508 条起；竞争债权人窗口 |
| 执转破 | 执行中移送 | 企业法人不能清偿到期债务且资产不足时 |
| 加倍部分债务利息 | 日万分之一点七五 | 法释〔2014〕8 号；与一般债务利息并行计算、互不冲抵 |
| 执行悬赏 | 申请执行人书面申请 | 费用由被执行人负担的条款可争取 |

## 二、施压端（对被执行人的措施期限）

| 措施 | 期限 | 要点 |
|---|---|---|
| 纳入失信名单 | 一般 **2 年**；暴力抗拒等情节严重可延长 1–3 年 | 期满未履行可重新纳入? 以现行规定为准 |
| 限制高消费 | 无固定期限，直至履行完毕或提供担保 | 对无财产被执行人约束力弱，但对家属有传导效应 |
| 限制出境 | 实务通常 1 年，可续 | 被执行人为自然人或法代/主要负责人时可用 |
| 拘留、罚款 | 拒执情形 | 与"拒执罪"（刑法的自诉/公诉路径）衔接 |
| 网络司法拍卖 | 流拍后 **30 日内**再次拍卖，降价幅度不超前次保留价 20% | 二拍流拍可变卖 |
| 审计调查 | 申请执行人申请，限被执行人为法人 | 摸清应收应付的强手段 |

## 三、时间线速判（拿到案卷先问三个日期）

1. **生效日** → 加倍利息起算、申请执行时效起算。
2. **终本日** → 恢复执行随时可提；距今日越久，"重新查控+新线索"的增量越大（银行流水、新任职、新征收都可能发生）。
3. **最后一次查控日** → 总对总查控距今超过 1 年，几乎必然要重新发起——房产购置、车辆登记、社保开通都可能发生在查控之后。

## 四、典型错误（勿犯）

- 把"终本 8 年"当"案子死了"——恢复执行无时效障碍。
- 把"终结执行"与"终结本次执行"混用——前者一般不可恢复，后者可。
- 加倍利息只算到申请恢复日——应算至实际履行日。
- 参与分配窗口错过——其他债权人对自然人被执行人执行终结前不申请，视为放弃该轮分配。
