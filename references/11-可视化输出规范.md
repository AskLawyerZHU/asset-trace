# 可视化输出规范（v1.3 新增）

> 定位：报告的**呈现层**规范。md 报告是数据层，永远是唯一事实来源——先写 md 后出图，图上每个数字必须能在报告里逐字找到。拒绝深色多板块 HTML 长卷，一切可视化以「一页式 SVG 速读」为形态。

## 一、总原则

1. **双轨制**：md 报告（完整、可存档、可检索）+ 一页速读图（给当事人/法官/团队 10 秒看懂）。两轨同源，禁止图上出现报告没有的数字。
2. **一页一主体**：每张图只讲一个被执行人；多主体出多张，不做拼盘。
3. **浅色固定**：白底、0.5px 边框、每个形状显式填色；字号下限 11px；仅 400/500 两档字重；无 emoji、无渐变阴影发光、无旋转文本。
4. **红黄绿语义全组件统一，不得反转**：红＝债务/风险/立即行动；琥珀＝待核（⏳）；绿＝资产/已闭合（✅）；蓝＝中性结构；灰＝公开不可查（⛔）。

## 二、四标色彩映射（所有组件共用）

| 状态 | 填充 | 描边/文字 | 文字语义 |
|---|---|---|---|
| ✅ 已核验 | #EAF3DE | #3B6D11 | 绿 |
| ⏳ 未查 | #FAEEDA | #854F0B | 琥珀，必附原因 |
| ⛔ 不可查 | #F1EFE8 | #5F5E5A | 灰 |
| ❗ 冲突 | #FCEBEB | #A32D2D | 红，两说并陈 |
| 中性结构 | #E6F1FB | #185FA5 | 蓝 |
| 新增/重点 | #FAECE7 | #993C1D | 橙红，粗描边 1px |

## 三、模块 → 组件映射（何时出什么图）

| 报告模块 | 组件 | 触发 |
|---|---|---|
| 全报告 | **一页速读图**（必出） | 每次深度/快速模式交付时 |
| 一、主体画像卡 | 画像卡（规格见五） | 必出（速读图顶部主体条即其压缩版） |
| 二、线索池 | P 级优先矩阵：横轴=可执行距离步数，纵轴=规模档，点径=金额，色=P 级 | P0+P1 ≥ 4 条时建议出 |
| 时间线（自然人） | 服刑+执行双轨时间线；本案终本节点放大标红 | 自然人默认并入速读图 |
| 版图（法人） | 股权/任职两层树；吊销/注销节点灰化、存续节点描边加粗 | 法人默认并入速读图 |
| 三、核对表 | 状态格子图：F1–F12 / N1–N9 一格一线，四态填色 | 并入速读图页脚（行数+四态统计） |
| 四、调查令清单 | checklist 卡按优先级分组 | 需要单独交付当事人时出 |
| 债权构成 | 金额分解条：本金/一般利息/加倍利息三段 | 构成 ≥ 2 项时并入速读图 |

## 四、一页速读图布局骨架

统一 680 宽（viewBox `0 0 680 H`，H=最底元素+20）。

**法人版**：标题带 → 主体条（画像卡压缩）→ 债务面/资产面双栏 → 新增发现带（橙红，无则省）→ 路径卡 ≤3 张 → 页脚统计。
**自然人版**：标题带 → 主体条 → 时间线（本案节点标红、今日节点琥珀）→ 债权构成条 → 路径卡 ≤4 张 → 已关闭条（绿，防重复投入）→ 页脚统计。

页脚必须含：核对表行数（=基线+扩展）+ 四态统计 + 报告文件名指引。

## 五、主体画像卡规格（重点组件）

```
┌──────────────────────────────────────────────┐
│ 主体名（16px/500）  [自然人|法人 徽章]   检索日期 │
│ [状态chips：登记状态·失信·限高·终本·严重违法]      │
│ 身份行：USCC/身份证(可脱敏) · 法代/出生 · 住所/户籍 │
│ ┌──────┬──────┬──────┬────────┐              │
│ │裁判文书│执行案件│终本件数│竞争债权人│ metric 块 │
│ └──────┴──────┴──────┴────────┘              │
│ 投资任职/任职行 ≤3 行，超出写「+N 家见报告表格」   │
└──────────────────────────────────────────────┘
```

- **chips 规则**：0 或无 → 绿底「无」；有记录 → 红底数字；未核 → 琥珀「待核」。chip 是画像卡的灵魂，一眼定风险。
- **metric 块**：灰底 #F1EFE8 圆角 8，上 12px 标签、下 20px/500 数字；数字必须与报告一致并取整。
- **高度预算**：≤10 行信息（与 07 模板画像卡要求一致）；放不下的进报告表格，卡上写「+N 见报告」。
- **脱敏**：对外分享版本身份证中间 8 位打码、姓名可保留（执行公开信息本就公示）；内部版按用户规则。

## 六、交付方式

1. 速读图在会话内直接渲染（速读组件，一调用一图，图间加文字过渡）；
2. 用户要求归档/转发时导出 `.svg`（可选 `.png`）存入案件目录 `财产线索检索/{主体}/`；
3. md 报告「〇、一页速读图」一节注明图已渲染/已导出的文件名。

## 七、工程约束（与渲染器对齐，出图前自检）

- viewBox `0 0 680 H`，680 不可变，`width="100%"`；安全区 x∈[40,640]。
- 字号：标题 15 / 节标题 13 / 正文 12 / 注 11（下限 11）；字重仅 400/500。
- 连接线 `fill="none"`；节点统一 rx=8；容器间距 ≥12px。
- 色值直接写死 hex（画布不解析 CSS 变量）；禁 `position:fixed`、禁外链字体。
- 出图前自检：图上数字 ⇄ md 报告逐一对得上？四态颜色有没有用反？一页是否讲完一个主体？
