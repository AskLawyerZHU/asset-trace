# 渠道卡：B 层半自动站点（人工待办生成用）

这些站点公开可查但需登录/验证码/交互。**不做自动化硬爬**；为每站生成"操作路径卡"（打开哪、点什么、输什么、抄什么回来），用户贴回结果后由本技能二次分析。

## 执行信息公开网 zxgk.court.gov.cn（最重要，四库分查）

| 库 | 入口 | 操作 |
|---|---|---|
| 综合查询被执行人 | 首页→综合查询被执行人 | 输姓名/名称+身份证号或组织机构代码→输验证码→记录案号、立案时间、标的、状态 |
| 失信被执行人 | 失信被执行人查询 | 同上；记录失信情形与作出时间 |
| 限制消费人员 | 限制消费人员查询 | 同上 |
| 终本案件 | 终本案件查询 | 同上；**终本=恢复执行入口，记录终本日期与未履行金额** |

要点：
- **四库必须分别查**，综合查询≠全库（实战：综合查询为空但终本库有案）。
- 验证码识别不了的，截图请用户输入；连续失败属正常，标 ⏳ 即可。
- 记录每库"查到 N 件 / 查到 0 件"，0 件也要留痕（截图或文字），供核对表使用。

## 动产融资统一登记公示系统（中登网）crd.creditmark.cn

应收账款质押/转让、融资租赁、保理、存货/仓单质押。五步查询法：
1. 选"登记查询"→ 按"质押人/承租人/转让人"名称查询；
2. 输入被执行人全名（法人）或姓名（自然人，命中少）；
3. 记登记编号、登记期限、担保财产描述、登记人（=谁是债权人）；
4. 展开登记详情抄"担保财产概况"；
5. 判断：在先质押=受偿顺序风险；**无在先质押只有实际查询后才能说"未查到记录"**，且写明查询日期。

## 全国司法拍卖（阿里资产 taobao.com 司法拍卖 / 京东拍卖 / 人民法院诉讼资产网）

- 按"被执行人姓名/公司名"搜索拍品与流拍记录；
- 流拍/变卖记录→该财产权属与评估值线索；
- 他人拍卖成功记录→该资产已变现，倒查案款分配。

## 人民法院公告网 rmfygg.court.gov.cn

- 检索公司名：破产公告、减资公告（**减资=追加股东未达标方向**）、清算公告、送达公告（含住址线索）。

## 全国企业破产重整案件信息网 pccz.court.gov.cn

- 检索债务人名：破产受理、管理人、债权申报期；已破产→申报债权或执转破评估。

## 国家企业信用信息公示系统 gsxt.gov.cn

- 年报原件（实缴、对外担保）、减资公示、简易注销公告期、经营异常、行政处罚。与第三方库冲突时以本站为准。

## 第三方风险库（企查查/爱企查/天眼查/水滴信用）

- 价值：**诉讼档案时间线**（案号+日期线，官方检索页没有）、关联风险、变更记录；
- 纪律：与官方源/元典冲突时标 ❗冲突两说并陈；"吊销/注销/存续"以公示系统为准；
- 免费门槛：部分信息需登录，能截到多少记多少，剩余列 ⏳。

## 国家知识产权局 / 中国版权保护中心

- 专利法律状态（终止、年费未缴、无效）；商标无效/撤销；软著登记。核实 A 层知产数据的"变现价值"。
